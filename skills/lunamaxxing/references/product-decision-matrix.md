# Product and Architecture Decision Matrix

Read this module for product direction, information architecture, workflow, system architecture, or other high-impact choices with meaningful alternatives.

## Define criteria before scoring

Derive 4–7 criteria from the quality brief. Include user outcome and evidence quality; add maintainability, reversibility, delivery cost, risk, compatibility, or differentiation only when relevant. Assign weights totaling 100. Do not choose criteria that merely justify a preferred answer.

## Compare coherent directions

For deep ambiguous work, compare the safe, structural, and distinctive directions. Score each 1–5 and attach a short evidence note to every consequential score.

## Decide without averaging away the idea

- Select one primary direction and state the decisive criterion.
- Record why each rejected direction loses.
- Do not blend incompatible interaction models or design theses into a compromise.
- Identify the cheapest reversible experiment when evidence is weak.
- Require user approval only when the choice materially changes scope, authority, or an irreversible outcome.
